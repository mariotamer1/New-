# ML Group — store website

- `site/` — the ready-to-upload website (also sent as `ml-group-website.zip`). Upload the contents to any static host (Netlify, Vercel, Cloudflare Pages, cPanel/Apache).
- `ML-Group.html` (built into `dist/`) — the whole store in one file; open it in a browser.
- Admin: click **Admin** in the footer, password `MLGROUP` (change it in Admin → Settings).

Build: `npm install && npm run build`. Source is in `src/`, images are generated by `scripts/images.py`.

Data: connected to the Supabase project "ML Group Store" (store.config.json). Admin changes, orders, offers and messages save to the live store instantly.
